# Общая информация по проекту

## Описание

Android-приложение для хранения и просмотра кулинарных рецептов с погодой и картой офисов.

## Стек и ограничения реализации

### Платформа

Android (Android Studio).

### Язык

Kotlin.

### UI-стиль

Material Design (Material Components / Material 3).

### Локальная БД

Room (SQLite).

### Загрузка изображений по URL

Coil или Glide (на выбор, можно иное).

### Сложность

Минимальная, пригодная для верстки начинающим Android-разработчиком.

### Дополнительные требования

- необходим функционал для работы с БД (например заметки);
- необходима "географическая" карта (Например: Google Maps, Yandex Maps, OpenStreetMap и тд.) - нужно вставить скриншот карты в то место, где она будет в приложении;
- необходимо использовать любой открытый API (например: погода, новости, курс валют, случайные анекдоты и т.д.), т.е. "нарисовать", как примерно будет выглядеть API (например, если будет прогноз погоды, то "рисуем" облачко и +5 градусов ).

## Модель данных

Единственная доменная сущность - это Recipe.

```kotlin
@Entity(tableName = "recipes")
data class Recipe(
    @PrimaryKey(autoGenerate = true)
    val id: Long = 0,

    val name: String,                 // Имя
    val imageUrl: String? = null,     // URL изображения (null -> плейсхолдер)
    val cookingTimeMin: Int,          // Время приготовления, мин
    val calories: Int,                // Калории, ккал
    val proteins: Int,                // Белки, г
    val fats: Int,                    // Жиры, г
    val carbs: Int,                   // Углеводы, г
    val ingredients: List<String>,    // Ингредиенты (список отдельных строк)
    val steps: String                 // Пошаговое описание (один текстовый блок)
)
```

Поле `ingredients: List<String>` Room напрямую не хранит - требуется TypeConverter
(например, join/split по разделителю).

## Экраны и навигация

Навигация осуществляется через боковое меню (Navigation Drawer), вызывается кнопкой в навбаре (app bar).
- Дашборд - стартовый экран.
- Мои рецепты - список рецептов.
- О нас - информация о компании + карта офисов.

Flow рецепта: карточка рецепта → страница рецепта → редактирование рецепта

Создание и редактирование рецепта - два отдельных экрана. Создание открывается с экрана
"Мои рецепты" и выполняет INSERT. Редактирование открывается со страницы рецепта и выполняет
UPDATE; на нём же доступно удаление.

### Дашборд

Header:
- Кнопка, открывающая navbar;
- По центру title: "Дашборд";

Main:
- Виджет погоды;
- Раздел с недавними рецептами
    - Заголовок "Недавние рецепты" с кнопкой "Все рецепты" (ведёт на экран "Мои рецепты");
    - Горизонтальная скролл-область с карточками недавних моих рецептов
        - Фото
        - Наименование
        - Время приготовления

### Мои рецепты

Header:
- Кнопка, открывающая navbar;
- По центру title: "Мои рецепты";

Main:
- Вертикальный список из моих рецептов в виде карточек
    - Наименование
    - Фото
    - В одну строчку
        - время приготовления в минутах
        - калорийность в килокалориях
- Прикреплённая снизу и по центру экрана кнопка создания рецепта:
    - Внутри кнопки иконка "Плюс"

### О нас

Header:
- Кнопка, открывающая navbar;
- По центру title: "О нас";

Main:
- Карточка с описанием компании
- Карточка с нашими офисами, внутри интерактивная карта (можно подвигать).

### Страница рецепта (просмотр)

Открывается нажатием по карточке рецепта. Режим по умолчанию, поля только для чтения.

Header:
- Кнопка "Назад" (стрелка влево) - слева;
- По центру title: наименование рецепта;
- Кнопка "Редактировать" (карандаш) - справа; переход в режим редактирования.

Main (карточка рецепта):
- Фото рецепта (или плейсхолдер, если `imageUrl` пуст);
- В одну строчку: "Время приготовления" (… мин) и "Калории" (… ккал);
- Блок "БЖУ на 100 г": белки, жиры, углеводы (в граммах);
- Раздел "Ингредиенты": список;
- Раздел "Пошаговое описание": текст одним блоком.

### Создание рецепта

Открывается из экрана "Мои рецепты" по кнопке "Плюс". Форма с пустыми полями; сохранение
создаёт новый рецепт (INSERT, `id` генерируется).

Header:
- Кнопка "Назад" - слева; возврат без создания;
- По центру title: "Новый рецепт";
- Кнопка "Сохранить" (галочка) - справа.

Main (форма):
- Поле "Имя";
- Поле "URL изображения";
- В одну строчку: "Время приготовления (мин)", "Калории (ккал)";
- В одну строчку: "Белки (г)", "Жиры (г)", "Углеводы (г)";
- Раздел "Ингредиенты":
    - Список строк-ингредиентов, у каждой кнопка удаления (⊗);
    - Кнопка "Добавить ингредиент" (плюс в круге);
- Поле "Пошаговое описание" (многострочное).

### Редактирование рецепта

Открывается со страницы рецепта по кнопке "Редактировать". Поля заполнены данными рецепта;
сохранение обновляет запись (UPDATE по `id`).

Header:
- Кнопка "Назад" - слева; возврат без сохранения;
- По центру title: "Редактирование";
- Кнопка "Удалить" (корзина) - по центру; открывает диалог подтверждения;
- Кнопка "Сохранить" (галочка) - справа.

Main (форма, заполнена текущими значениями):
- Поле "Имя";
- Поле "URL изображения";
- В одну строчку: "Время приготовления (мин)", "Калории (ккал)";
- В одну строчку: "Белки (г)", "Жиры (г)", "Углеводы (г)";
- Раздел "Ингредиенты":
    - Список строк-ингредиентов, у каждой кнопка удаления (⊗);
    - Кнопка "Добавить ингредиент" (плюс в круге);
- Поле "Пошаговое описание" (многострочное).

Удаление:
- По кнопке "Удалить" открывается диалог подтверждения (заголовок, текст, кнопки "Отмена" / "Удалить");
- При подтверждении - DELETE записи и возврат к списку "Мои рецепты";
- При отмене - диалог закрывается, рецепт остаётся.
