# Книга Рецептов

Android-приложение для хранения и просмотра кулинарных рецептов с интеграцией внешних сервисов (погода и карты).

---

## Руководство пользователя

### 1. Главный экран (Дашборд)
*   **Погода**: В верхней части экрана отображается виджет с текущей погодой по вашей геолокации. При первом запуске приложение запросит разрешение на доступ к местоположению. Данные загружаются через **Open-Meteo API**. Вы увидите город, температуру, влажность и скорость ветра.
*   **Недавние рецепты**: Горизонтальный список последних добавленных вами рецептов. Нажатие на элемент списка открывает подробную информацию о рецепте.

### 2. Мои рецепты
*   Список всех ваших рецептов.
*   **Поиск**: Используйте строку поиска сверху для фильтрации рецептов по названию.
*   **Создание**: Нажмите кнопку «+» (FAB) для добавления нового рецепта. Укажите название, время приготовления, калории, белки, жиры, углеводы и описание.

### 3. Детали рецепта
*   Просмотр полной информации о блюде.
*   **Редактирование**: Кнопка «карандаш» в верхнем баре позволяет изменить данные.
*   **Удаление**: Кнопка «корзина» удаляет рецепт из базы.

### 4. О нас (Карта)
*   Раздел с информацией о компании.
*   **Карта**: Используется **Yandex MapKit**. На карте отмечены офисы компании (используются контрастные чёрные метки).
*   **Взаимодействие**: Вы можете перемещать карту. Для управления масштабом используйте кнопки **«+»** и **«-»** в правом нижнем углу карты. При нажатии на иконку офиса появится всплывающее уведомление с его названием.

## Инструкция по сборке APK средствами CLI

### Предварительные требования

| Инструмент | Версия |
|---|---|
| JDK | 17 или выше |
| Android SDK | API 35 |

Убедитесь, что переменная окружения `ANDROID_HOME` указывает на папку Android SDK, либо что в файле `local.properties` прописан путь:

```
sdk.dir=C\:\\Users\\<username>\\AppData\\Local\\Android\\Sdk
```

---

### Подготовка

Проект требует API-ключ Яндекс Карт для работы экрана «О нас». В корне проекта в файле `local.properties` должна быть строка:

```
MAPKIT_API_KEY=ваш_ключ
```

**Важное примечание по базе данных:**
В версии 3 была изменена схема данных (удалены координаты из рецептов). В приложении настроена деструктивная миграция (`fallbackToDestructiveMigration`), что означает **полную очистку локальной базы данных** при первом запуске новой версии. 

Если вы столкнулись с ошибками при запуске, рекомендуется полностью удалить приложение с устройства и установить его заново.

---

### Сборка debug-APK

Откройте терминал в корне проекта и выполните:

```bash
./gradlew assembleDebug
```

На Windows:

```bat
gradlew.bat assembleDebug
```

Готовый файл будет по пути:
`app/build/outputs/apk/debug/app-debug.apk`

---

### Полезные команды

```bash
# Очистить артефакты предыдущей сборки
./gradlew clean

# Очистить и собрать заново
./gradlew clean assembleDebug

# Установка на подключённое устройство
./gradlew installDebug
```
